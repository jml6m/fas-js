State Machine Simulator

This is the original 2019 simulator. It runs the fas-js release it was written for. Open the current demo

Machine

Names separated by commas, no spaces.

One character each, separated by commas. An NFA already has ε.

Kind of machine

One line per transition: origin,symbol,destination. Every state needs a line for each symbol.

One line per transition: origin,symbol,[destination|destination]. Leave the symbol blank for an ε-move.

Start and accept states

Press a state to change its role: start, then start and accept, then accept, then none.

Graph

Apply the states and the alphabet, fill in the transitions, then choose Generate FSA. The graph is drawn here.

One string with no spaces, unless a space is a symbol.
