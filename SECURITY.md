# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's private vulnerability reporting:
<https://github.com/jml6m/fas-js/security/advisories/new>

### What to include

- Affected version (npm version or commit SHA) and install method
- Steps to reproduce, with a minimal proof of concept if possible
- Impact and any suggested fix

### Scope

- **In scope:** the published `fas-js` npm package — the `createFSA` / `simulateFSA` / `stepOnceFSA` API.
- **Out of scope:** the GitHub Pages demo site and its bundled third-party libraries (D3, Graphviz WASM), and issues that require a modified build of the library.

There is no bug-bounty program.
